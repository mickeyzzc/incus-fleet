# Incus Fleet Web 端全面 E2E 测试流程（草案 v1）

> 目标：全部通过浏览器 UI 完成真实操作，不直接调用 API/CLI。
> 原则：任何「Web 上做不到 / 做错 / 难做」的情况都记为缺陷（BUG）或体验问题（UX），最后统一修复。
> 执行时按用例编号逐条进行，结果记录到 `issues.md` / `ux-improvements.md`。

## 0. 执行前置条件（需确认）

| 项 | 内容 |
| --- | --- |
| Web 地址 | 待提供（例如 `http://<host>:8080`） |
| 登录方式 | 管理员 token / 本地账号 + 密码（待提供） |
| 测试集群 | 至少 2 个在线集群；其中目标集群为「63集群」 |
| 测试节点 | `oldpcserver`（位于 63 集群，用于删除/加回/修改/配置） |
| 安装介质 | Debian / Ubuntu / Arch Linux 的 ISO 与镜像文件已可用 |
| 破坏性操作授权 | 删除节点、删除互联、删除实例/镜像等必须在确认后执行 |
| 快照/备份 | 操作前对关键数据做备份或确认环境可重建 |

> 重要：`oldpcserver` 的删除/加回、互联删除属于真实破坏性操作，执行前需用户二次确认。

## 2. 详细用例

### A. 登录 / 导航 / 权限 / 语言 / 会话

- **A1 登录**：打开首页 → 输入凭证 → 成功进入 dashboard。检查错误密码提示、空输入校验。
- **A2 会话过期**：等待/模拟会话过期 → 自动跳转登录页 → 登录后回到原页面。
- **A3 语言切换**：齿轮菜单切换 中文/English，验证所有页面与弹窗文案即时生效、刷新后保持。
- **A4 侧边栏导航**：逐个访问 Dashboard / 集群 / 实例 / 迁移 / 镜像与自动化 / 存储 / 插件 / 用户，检查空白页与路由错误。
- **A5 角色权限**：创建 Viewer/Operator 账号登录，验证只读账号看不到/点不动修改入口，且 API 被拒（403）有友好提示。
- **A6 用户管理**：创建用户（密码强度、必填校验）、编辑角色、重置密码、禁用/启用、删除；验证「最后一个管理员不可删除/降级」。
- **A7 帮助与关于**：打开 Help 对话框，检查内容、链接、关闭行为。
- **A8 浏览器兼容/刷新**：F5 刷新深链接页面不丢失位置；后退/前进正常。

### B. 镜像与自动化资产

- **B1 镜像导入（单文件）**：Images & automation → Images → Import，选择统一 tar 文件，设置 type（container/VM）与 alias，确认出现在列表。
- **B2 镜像导入（分离文件）**：同时选择 metadata tar + `.root` rootfs 文件导入，验证成功。
- **B3 镜像导入异常**：空文件、错误类型、超大文件（>8GiB 边界提示）、重复 alias，检查错误提示是否清晰。
- **B4 镜像分发**：在源集群 Distribute 到另一集群，核对 fingerprint 一致；检查目标已存在时的处理。
- **B5 缓存镜像刷新**：对 cached 镜像执行 Refresh，核对 fingerprint 变化、alias 保持。
- **B6 镜像删除**：确认弹窗、取消与确认路径；删除被引用的镜像时的提示。
- **B7 ISO 上传**：上传 Debian/Ubuntu/Arch ISO 到指定存储池，检查容量校验、重名处理、进度、失败回滚。
- **B8 SSH 公钥库**：新增（名称/内容）、重复内容去重、编辑、删除；注入时不部署仅保存。
- **B9 脚本库**：新增脚本（名称/描述/正文）、编辑、删除、必填校验。
- **B10 应答文件（Answer profiles）**：为 Debian/Ubuntu/RHEL/Generic 四种 installer 创建 profile，设置默认，验证自动套用与编辑/删除。

### C. 无人值守安装（重点）

> 分别验证两条路径：**ISO 无人值守**、**镜像（cloud image）方式**；覆盖 Debian、Ubuntu、Arch Linux。

- **C1 ISO → Debian**：ISO 列表 → Create VM → 填写 VM 名、网络、根盘大小 → 开启 Unattended install → 选择 Debian/d-i preseed → 填模板字段 → **Preview answer file** 检查内容 → Start。验证派生 ISO 生成、自动启动、安装完成自动关机、介质自动卸载与派生卷清理、开机进入系统。
- **C2 ISO → Ubuntu**：同上，profile = Ubuntu autoinstall (Subiquity)；验证 NoCloud seed ISO 作为第二介质挂载；检查 cloud-init 用户/密码生效。
- **C3 ISO → Arch Linux**：Arch 无官方无人值守 profile，验证 Generic cloud-init / 手动安装路径是否可用；如不可用记录 BUG/UX。
- **C4 镜像 → Debian/Ubuntu/Arch**：使用已导入的 cloud 镜像创建 VM/容器，验证选择镜像、网络、资源限制、Start after creation，启动后检查系统版本、网络 DHCP、磁盘大小。
- **C5 应答文件三种来源**：模板字段 / 保存的 profile / 自定义粘贴，分别验证；检查 profile 默认值自动填充。
- **C6 profile 猜测**：根据 ISO 文件名自动推测 installer 类型是否正确；错误时是否可手动纠正。
- **C7 远程桌面跟随安装**：打开 Remote desktop 观察 GRUB 自动引导（10s）、安装画面、分辨率自适应、键盘/鼠标/滚轮注入。
- **C8 安装后处理**： shutting down → 卸载 ISO → 启动进入系统 → 验证 hostname/用户/密码/时区/locale/磁盘分区。
- **C9 异常**：work_dir 空间不足、xorriso 缺失、ISO 不支持的 profile、安装超时（6h watch）时的提示是否友好。

### D. 容器部署服务（≥3 个）

- **D1 Nginx 容器**：基于 Debian/Ubuntu 镜像创建容器，选择物理 NIC 获取同段 IP，启动后 Terminal 安装 nginx，验证 HTTP 访问。
- **D2 PostgreSQL 容器**：按用户指南流程安装 PostgreSQL，配置密码/监听/允许网段，验证本地与跨机连接。
- **D3 Redis 容器**：创建容器安装 Redis，验证 ping/端口可达。
- **D4 服务发现**：在实例列表核对 3 个服务的名称、状态、IP、所属集群/节点。
- **D5 文件管理**：向容器上传配置文件、下载、新建目录、删除文件，验证权限与结果。
- **D6 维护操作**：Run script / Set password / Inject SSH key，验证退出码、stdout/stderr、SSH 免密登录生效。

### E. 资源变更（磁盘 / CPU / 内存 / 网卡）

- **E1 CPU 修改**：编辑实例，修改 CPU 限制，确认生效并核对配置。
- **E2 内存扩容/缩小**：修改内存值，核对单位与生效；**重点检查是否需要单位下拉框、是否只能输入数字**（见 UX-01）。
- **E3 根磁盘扩容**：在线/离线扩容 root disk，验证大小更新、文件系统是否需手动 grow、数据不丢失。
- **E4 添加数据盘**：Devices → Attach disk（存储卷 / host path），验证挂载。
- **E5 修改磁盘**：编辑已挂载磁盘（大小、路径、读写），验证 merge 保留 boot priority 等未管理键。
- **E6 删除磁盘**：Detach / 删除卷，确认数据卷与实例卷的区别、确认弹窗。
- **E7 添加网卡**：Devices → Attach NIC，选择 managed 网络或 macvlan 物理网卡，验证 IP 分配。
- **E8 修改网卡**：切换网络、改静态地址、清空地址回退 DHCP；验证 legacy nictype/parent 重写。
- **E9 删除网卡**：Detach  nic，验证网络中断与列表更新。
- **E10 网卡 bond 场景**：选择 bond 从属 NIC 应被禁止/隐藏，选择 bond 本身可用。
- **E11 端口转发**：Attach proxy device，配置 listen/connect，验证外部访问。
- **E12 非法值**：负数、0、超大值、非数字、带单位字符串粘贴，检查前端校验与错误提示。

### F. 实例运维

- **F1 启动/停止/重启**：含 force 选项与确认弹窗、取消路径。
- **F2 改名（Rename）**：验证实例改名入口是否存在；改名后名称、IP、设备、快照引用是否一致（无入口记 BUG）。
- **F3 克隆**：Clone 实例，新名称、可选启动，核对磁盘与配置复制。
- **F4 快照**：创建（含状态）、列出、恢复（确认弹窗）、删除。
- **F5 镜像升级/重建**：Rebuild 到新镜像，验证停机要求、root disk  wiped、数据盘保留。
- **F6 跨集群迁移（copy）**：实例从一个集群复制到另一个集群，核对快照可选、进度、结果。
- **F7 跨集群迁移（move）**：迁移实例，验证源删除、目标存在、运行 VM 的 stateful 条件校验。
- **F8 迁移失败回滚**：目标不可用/存储池缺失/中断时，验证源自动重启、失败状态提示、重提交入口。
- **F9 迁移后网络**：验证 DHCP 续租、IP 落在目标子网、网关/路由正确。
- **F10 Terminal Exec**：持久化 shell、多命令、窗口缩放、中断信号、断开重连。
- **F11 Serial Console**：VM console 输出、关闭码 1006 的友好处理。
- **F12 Remote desktop**：电源控制、重启/停止、键盘 Ctrl+Alt+Del、指针与滚轮。
- **F13 删除实例**：确认弹窗、勾选删除附加卷、ISO 介质保留、取消路径。
- **F14 实例详情抽屉**：Tabs（概览/网络/设备/快照/监控）、实时指标 3s 刷新、停止实例仅显示状态行。

### G. 批量操作与监控

- **G1 多选实例（跨集群）**：勾选后批量工具栏出现，刷新后勾选保持。
- **G2 批量注入密钥**：选 key → 注入 → 每实例成功/失败与退出码。
- **G3 批量运行脚本**：选脚本 → 执行 → 输出与退出码展示。
- **G4 批量电源操作**：start/stop/restart，验证部分失败处理。
- **G5 集群监控**：dashboard 每 15s 刷新、成员上线/离线状态、资源条。
- **G6 实例监控**：CPU/内存/磁盘/网络图表、峰值/swap/累计流量、rate 曲线。

### H. 集群与节点（63 集群重点）

- **H1 集群注册**：通过 UI 添加集群（endpoint/cert/project），验证连接测试与在线状态。
- **H2 集群编辑/重连**：修改显示名、端点、重新连接；离线集群错误提示。
- **H3 节点列表**：查看 63 集群成员、角色、状态、资源。
- **H4 删除 oldpcserver**：二次确认 → 从集群移除 → 列表更新；验证确认文案是否明确、是否有影响提示。
- **H5 加回 oldpcserver**：Add node 对话框，agent-first 流程：创建 enrollment token → 显示一次性命令 → 等待 agent 上线 → Bootstrap via agent（或 Use SSH instead）。验证 member 名匹配、包安装开关、失败提示。
- **H6 修改节点**：编辑节点名称/角色/地址等可改字段，验证保存与刷新。
- **H7 配置节点**：Node network 页面配置 NIC 状态、地址、路由、防火墙、Wi-Fi；验证 backend 显示、写入权限校验。
- **H8 节点操作历史**：History 打开 task/audit 时间线，检查动作、backend、状态、时间、密码脱敏。
- **H9 Agent 管理**：一次性 token 创建、安装命令、上线状态、证书轮换/吊销、升级、重启。
- **H10 Host metrics**：节点详情 Source 切换 Center 1h / Prometheus，导出 json/prometheus/csv。
- **H11 SSH 路径**：无 agent 时使用 SSH，sudo 密码仅本次使用不存储。
- **H12 节点升级**：NodeUpgradeDialog 流程与结果校验。

### I. 私有互联网络（跨节点内网互联）

- **I1 启用互联**：集群页 Private interconnect → Enable，填写 subnet、VNI、gateway member、MTU、DHCP range，确认创建。
- **I2 验证互联**：跨节点实例获取同段 DHCP 地址、互相 ping 通、网关/NAT 正常、MTU 正确。
- **I3 修改互联**：修改 subnet/VNI/MTU/gateway/DHCP range，验证重建与实例网络不中断。
- **I4 新增节点后 Reconcile**：加回 oldpcserver 后执行 Reconcile，验证隧道 full mesh 重建、新节点加入。
- **I5 删除节点后 Reconcile**：删除节点后执行，验证隧道清理。
- **I6 删除互联**：Disable → 验证隧道、dnsmasq、NAT、fleetbr0 全部清理，实例网络回退。
- **I7 异常**：非法 subnet/VNI、gateway 选错、reconcile 失败时的提示与回滚。

### J. 基础设施

- **J1 集群概览**：Overview & nodes tab 的容量、成员、版本、状态。
- **J2 创建/编辑/删除 managed network**：验证名称、CIDR、bridge、DHCP。
- **J3 网络删除受阻**：被实例使用的网络删除时的提示。
- **J4 存储池**：创建（dir/lvm/zfs 等）、编辑、删除；容量与驱动展示。
- **J5 自定义存储卷**：在池下创建、删除卷，挂载到实例。
- **J6 FleetVolumes 页面**：跨集群存储列表与操作。
- **J7 Profiles**：创建、编辑配置模板、删除；创建实例时选择 profile 生效。
- **J8 集群 Images & media tab**：镜像与 ISO 统一管理视角。
- **J9 迁移记录**：Migrations 页面任务列表、状态标签、重试/取消、历史清理。

### K. 管理面

- **K1 插件**：Plugins 页查看、启用/禁用、作用域 API token 管理。
- **K2 任务与审计**：任务列表、状态、审计日志查询、200 行限制提示、导出。
- **K3 设置**：语言、外观、账号信息。
- **K4 通知/消息**：ElMessage 成功/失败提示的准确性与可关闭性。
- **K5 空状态**：无集群/无实例/无镜像时的引导文案。
- **K6 加载状态**：骨架屏/loading、慢请求反馈、重复提交防抖。
- **K7 i18n 完整性**：中英文切换后无 key 泄漏（如 `cluster.create` 原文）。
- **K8 无障碍**：键盘 Tab 导航、按钮可聚焦、对比度。

### L. 异常、边界与回归

- **L1 表单必填/格式校验**：所有弹窗空值、非法字符、超长文本。
- **L2 网络异常**：后端 500/错误响应时页面不崩溃、有重试入口。
- **L3 并发操作**：同一资源快速重复点击、多标签页同时操作。
- **L4 大数据量**：数百实例/镜像列表分页、搜索、排序、虚拟滚动。
- **L5 长任务进度**：上传/迁移/安装期间的进度、取消、页面切换后状态保持。
- **L6 浏览器刷新**：每个弹窗打开时刷新，验证状态不残留。
- **L7 删除确认**：所有破坏性操作必须确认、文案说明影响。
- **L8 数据一致性**：UI 显示与后端实际配置一致（抽查 10 项）。
- **L9 回归**：修复后重跑相关用例。
- **L10 截图留证**：关键页面与问题现象截图存档。

## 3. 问题记录规范

每条问题记录到 `issues.md`，格式：

```markdown
### BUG-001 简短标题
- 用例编号：C1
- 严重级别：Blocker / Critical / Major / Minor
- 环境：集群 / 节点 / 浏览器
- 复现步骤：1. 2. 3.
- 实际结果：
- 期望结果：
- 截图/日志/网络请求：
- 定位（文件:行号）：
- 修复方案：
- 状态：待修复 / 已修复 / 已验证
```

UX 问题记录到 `ux-improvements.md`，格式：

```markdown
### UX-001 内存输入需明确单位并限制为数字
- 用例编号：E2
- 现状：单个文本框，用户需自行输入 "1024MiB" 这类混合字符串
- 问题：认知负担高，易输错单位/格式
- 建议：单位下拉框（MiB/GiB）+ 纯数字输入框，前端按所选单位拼接
- 影响范围：所有资源大小输入（内存、磁盘、ISO 根盘、DHCP range 等）
- 优先级 / 状态
```

## 4. 预估的体验优化方向（待实测确认）

- **UX-01 资源单位**：内存/磁盘增加单位下拉框 + 纯数字输入（用户示例）。
- **UX-02 数值范围提示**：CPU/内存/磁盘显示当前值与上限、允许范围。
- **UX-03 危险操作分级**：删除节点/互联/实例需输入名称确认，而非仅点「确定」。
- **UX-04 单位统一**：全站 B/MiB/GiB、ms/s 等统一展示与输入。
- **UX-05 表单即时校验**：失焦即校验并显示错误，不等到提交。
- **UX-06 长任务可观测**：安装/迁移/分发显示分阶段进度和预计时间。
- **UX-07 的空状态引导**：无介质/无镜像时给出「去上传/去导入」直达按钮。
- **UX-08 错误可操作**：错误提示附带「重试/查看日志/联系管理员」动作。
